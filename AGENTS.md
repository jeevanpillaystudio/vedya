# Vedya

A generative design system for geometric patterns and modular parts, built for fabrication (CNC milling, 3D printing, laser cutting). The original code was a Fusion 360 script; it is being rewritten on build123d, an open-source Python CAD library, on the branch `claude/vedya-cad-port`.
